KeyPOS New - Android Project
===========================

HOW TO BUILD THE APK (on your PC):

1. Install Android Studio (free):
   https://developer.android.com/studio

2. Open Android Studio → Open → select this folder (apk-project)

3. Wait for it to sync (first time downloads some files)

4. Menu: Build → Build Bundle(s) / APK(s) → Build APK(s)

5. Find the APK at:
   app/build/outputs/apk/debug/app-debug.apk

6. Copy to your phone, tap to install.
   (Allow "Install unknown apps" when asked)

That's it! The app has all 1,522 products built in.

PROJECT CONTENTS:
- app/src/main/assets/KeyPOS-New.html = your full software
- app/src/main/java/com/keypos/mobile/MainActivity.java = app wrapper
- All config files ready, no changes needed.
